# 手がかり想起カード

絵を覚えて、少し気をそらしたあと、**ヒント（手がかり）** をたよりに思い出す記憶トレーニング。
認知機能検査の「手がかり再生」の練習用。
HTML 1枚で動く（ビルド不要、`index.html` をブラウザで開くだけ）。絵は絵文字なので画像ファイルもいらない。

## 1ラウンドの流れ

1. **覚える** … カテゴリがちがう絵が並ぶ（例：くだもの・りんご／どうぶつ・ライオン）。
   時間が来るか「覚えた！」で伏せられる
2. **数字タップ** … 数字を大きい順にタップして気をそらす
3. **思い出す** … 1枚ずつ、ヒントつきの4択で答える
   - 「さっきの絵の中で **くだもの** は何でしたか？」（カテゴリがヒント）
   - 「🐘ぞう と同じなかまで、さっき見たのは どれ？」（同じなかまの別の絵がヒント）
   - 選択肢は4つとも同じなかまなので、覚えていないと当てられない
4. **ふりかえり** … 覚えた絵を、思い出せた○／思い出せなかった× つきで見直す

## ラウンド構成（全5ラウンド・30枚）

| ラウンド | 絵の枚数 | 覚える時間 | 数字タップ |
|---|---|---|---|
| 1 | 4枚 | 12秒 | 6こ（1〜30） |
| 2 | 5枚 | 13.5秒 | 6こ（1〜30） |
| 3 | 6枚 | 15秒 | 9こ（1〜99） |
| 4 | 7枚 | 16.5秒 | 9こ（1〜99） |
| 5 | 8枚 | 18秒 | 9こ（1〜99） |

- 絵は14カテゴリ（くだもの・やさい・どうぶつ・のりもの・鳥・海の生きもの・虫・楽器・花・スポーツ・料理・おかし・着るもの・道具）から毎回ランダム。1ラウンドの中でカテゴリは重ならない
- 最後に合計スコアと星（9割以上で★3、7割以上で★2）。星3つ・全問正解で紙吹雪

## 操作

| | |
|---|---|
| 選択肢 | タップ / キーボード `1`〜`4` |
| 覚えた・つぎへ・はじめる | ボタン / `Enter` |
| 音を消す | 右上の 🔊 |
